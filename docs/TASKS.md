# AURA Citation Navigator — Task Tracker

Repo-native progress tracker. Kept in sync with git commits (see "How to update" below).
Mirror the high-level status into the Google Sheet whenever you want a shareable view.

**Status key:** `[ ]` not started · `[~]` in progress · `[x]` done · `[!]` blocked
Annotate each task with a short status/date, e.g. `— Done 2026-08-14` or `— Blocked: GROBID setup`.

## How to update (after a work session)
Review the git commits since the last update, then check off completed tasks, mark
in-progress ones `[~]`, and add the date. Leave a one-line note on anything blocked.
Task text and IDs stay as they are.

## Phase 2 · Citation Bridge (Cited-Span Localization)
- [x] **2.1** Detect citation anchors → map to reference entries — Done 2026-10-26: `app/core/citations.py` + `GET /papers/{id}/citations`. Handles numeric (`[13]`, `[2, 19]`, `[1–3]`, labels `[n]` and `n.`) and author-year (parenthetical, narrative, multi-citation, `2018a,b`) — 4 and 6 of the samples. **915/923 citations linked (99.1%), 510/513 references cited (99.4%), 0 inconsistent links**; every remaining miss checked by hand and absent from the source. Built as a separate artifact from the parse so it never invalidates cached rankings. GROBID not needed yet. Gate: `scripts/qa_citations.py`. 170 backend tests (was 143)
- [x] **2.2** Reference resolution via Semantic Scholar / arXiv API — Done 2026-10-26: `app/scholar/client.py` (one process-wide rate limiter, disk cache, failures never cached) + `app/core/resolution.py` + `POST /papers/{id}/references/resolve`. Matches each entry to the citing paper's own Semantic Scholar reference list by title (1 request per paper), then printed arXiv ids/DOIs in one batch; per-entry title search is opt-in. **495/513 references resolved (96.5%), 370/513 with a fetchable PDF (72.1%)**; every inexact match checked by eye. Found a wrong match ("fifth" vs "sixth" PASCAL challenge) and fixed it. 192 backend tests (was 170)
- [x] **2.3** Fetch cited paper full text (open-access; abstract fallback) — Done 2026-11-04: `app/scholar/download.py` (SSRF guard on every redirect hop, 50 MB cap while streaming, `%PDF-` check, per-host pacing — arXiv 3s) + `app/core/cited_text.py` + `POST /papers/{id}/references/{ref}/text`. Ladder: arXiv → ACL Anthology → open-access PDF → Semantic Scholar abstract → OpenAlex (PDF, then abstract) → `unavailable` with reasons; a fetched PDF is parsed and stored as an ordinary paper. On the first 8 references of each sample: **60/80 full text (75%), 10 abstract (8 from OpenAlex), 10 unavailable; 93.3% of resolved references have some text (bar: 85%)** — with a free `OPENALEX_API_KEY`; 90.7% without, as keyless search gets throttled. Remaining misses: paywalls (ACM, Elsevier, Wiley) and workshop papers. 236 backend tests (was 192)
- [x] **2.4** Segment cited paper into candidate passages — Done 2026-11-04: `app/core/passages.py` + `GET /papers/{id}/passages`. Windows of 1–3 consecutive sentences inside one section (overlapping; 2.5 must suppress near-duplicates in its top-k); abstract-only papers windowed the same way. Left out, counted by reason: the reference list (citation detector, else a section titled References), text after the references unless its heading looks like an appendix, acknowledgments, and non-prose (table rows, author lines, figure debris — front matter is kept, since the abstract often lives there). On 61 papers (10 samples + 51 fetched): median 48% of sentences kept, ~640 passages per paper; no paper's kept text looks like a reference list (leak alarm at 2%; its recall on removed bibliography: 43%). 251 backend tests (was 236)
- [x] **2.5** Localizer v1 — embedding retrieval (Specter2 / MiniLM) — Done 2026-11-05: `app/core/embedding.py` (lazy-loaded MiniLM behind a protocol; passage embeddings cached on disk by model + texts) + `app/core/localizer.py` + `POST /papers/{id}/citations/{anchor}/localize?k=`. Query = the citing sentence with every citation marker removed; cosine ranking; overlapping windows suppressed so the top-k are distinct places; the result says whether full text or only the abstract was searched. Eyeballed on 19 real citations (no ground truth until 2.6): plausible top-1 for most, e.g. 0.97 on Caruana's own definition of multitask learning; vague citances score ~0.45. Found the cited paper's **title ranking first in 4/19** → 2.4 now drops titles and headings (passage v2). ~12s cold (model load), ~2s per citation after. Production image gets numpy only; without torch `/localize` answers 503. 270 backend tests (was 251)
- [x] **2.6** CL-SciSumm eval harness (overlap F1, ROUGE, acc@k) — Done 2026-11-05: `eval/localization/` (`clscisumm.py` loader, `metrics.py`, `run_clscisumm_eval.py`, 11 tests). The canonical WING-NUS repo is gone from GitHub; uses a complete mirror (`robinsdeepak/scisumm-corpus-fs`, provenance in the loader). Evaluates on the 40 human-annotated papers / **753 citances** of the 2019 training set (the mirror's 2018 test gold is empty; ScisummNet's annotations are automatic). Reference papers are rebuilt from the corpus's own sentences so gold ids = our ids; candidates and ranking are the app's own code (2.4, 2.5). Sentence-overlap F1 computed as the official 2018 script does (read, not run). Fixed dev/test split by paper (313 / 440 citances). **Baseline (MiniLM, all): acc@1 17.0%, @5 46.1%, @10 61.6%, F1 0.122, ROUGE-L 0.24; random: acc@1 1.3%, F1 0.010; gold reachable after 2.4's exclusions: 97.9%.** For scale only: the 2019 overview reports a best Task 1A F1 of 0.126 — on a different test set
- [x] **2.7** Evaluate localizer v1 (baseline) — Done 2026-11-06: five rankers compared on the CL-SciSumm **dev** split, the winner checked once on **test**. Dev F1 / acc@1: hybrid BM25 + MiniLM (α 0.7) **0.182 / 21.7%**, BM25 0.152 / 17.9%, MiniLM 0.130 / 17.3%, mpnet 0.112 / 14.7%, SPECTER2 + proximity adapter 0.108 / 15.3%; single-sentence candidates hurt (13.4%). **Test: hybrid F1 0.166, acc@1 23.0%, acc@5 54.3%** (BM25 0.146 / 20.5%, MiniLM 0.112 / 16.8%, random 0.009 / 0.9%). Raw score is a weak confidence signal; the lead over the runner-up is a strong one: margin ≥ 0.75 (picked on dev) flags 23% of test citances as clear matches, right 35.6% of the time vs 23.0% overall. The app now serves the hybrid (localizer v2, `app/core/lexical.py`) with a `clear_match` flag. 287 tests (backend + eval)

- [x] **3.4** Grounded-evidence tool (RAG over cited paper via localizer) — Done 2026-11-10 (backend): `app/core/evidence.py` + `POST /papers/{id}/citations/{anchor}/ask`. Retrieves with the 2.7 hybrid (top 6 for the question + top 2 for the citing sentence, no overlaps) from the cited work's text (2.3/2.4); Gemini answers in at most four claims, each naming a passage and **quoting it**; every quote is checked verbatim against the passage it names, and failures are dropped and counted. Model says it cannot tell, or nothing survives → `insufficient`, never a guess. Answers cached by question; own daily budget (30, 10 per visitor), charged only when the model is called. Live on the Bahdanau citation: a mechanism question answered with 3 verified quotes; "capital of France?" → insufficient.
